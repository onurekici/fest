## 🇬🇧 English Documentation

### **System Overview**
**FNFest Rank System** is a high-performance, automated data archiving tool developed for the Fortnite Festival mode. It utilizes the Epic Games API to track, encrypt, and store global leaderboard standings in an open data format.

### **🚀 Next-Gen Features**

* **⚡ 6x Turbo Parallel Processing (Matrix Strategy):**
    Powered by GitHub Actions Matrix, the system scans 6 different instrument categories (Guitar, Bass, Vocals, Drums, Pro Lead, Pro Bass) **simultaneously**. This minimizes execution time and ensures real-time data synchronization.
* **🔒 AES-256 Data Encryption:**
    Fetched data is encrypted with military-grade **AES-256** encryption immediately upon retrieval. This ensures that the raw data remains tamper-proof and secure within the repository artifacts.
* **📂 Optimized Artifact Storage:**
    Instead of bloating the Git history, data is stored in compressed and encrypted "Artifact" packages, keeping the repository lightweight and fast.

### **📊 Data & Statistics**
The system generates detailed, paginated JSON files containing:
* **Rank & Score:** Global player ranking and total scores.
* **Performance Metrics:** Accuracy percentage, Stars earned, and Difficulty levels.
* **Full Combo (FC):** Detection of flawless runs.
* **Session History:** Detailed match statistics beyond just the `best_run`.

### **🔒 Security & Privacy**
* **No Personal Data:** This project accesses only **publicly available** leaderboard data (Display Names, Scores). No emails, passwords, or payment info are accessed.
* **Secure Secrets:** All sensitive credentials (Refresh Tokens, Client Secrets) are stored in **GitHub Secrets** and are never exposed in the source code.

## 🇹🇷 Türkçe Dokümantasyon

### **Sistem Hakkında**
**FNFest Rank System**, Fortnite Festival modu için geliştirilmiş yüksek performanslı bir veri arşivleme aracıdır. Epic Games API'sini kullanarak küresel liderlik tablolarını takip eder, şifreler ve açık veri formatında saklar.

### **🚀 Yeni Nesil Özellikler**

* **⚡ 6x Turbo Paralel İşlem (Matrix Stratejisi):**
    GitHub Actions Matrix yapısı sayesinde; Gitar, Bas, Vokal, Bateri, Pro Gitar ve Pro Bas olmak üzere 6 farklı kategoriyi **aynı saniyede** tarar. İşlem süresini minimuma indirir.
* **🔒 AES-256 Veri Şifreleme:**
    Çekilen veriler, sunucudan alındığı an askeri standartlarda **AES-256** ile şifrelenir. Bu, verilerin depo içinde güvenli ve değiştirilemez kalmasını sağlar.
* **📂 Optimize Edilmiş Depolama:**
    Veriler Git geçmişini şişirmek yerine, sıkıştırılmış ve şifrelenmiş "Artifact" paketleri halinde saklanır. Bu sayede depo her zaman hızlı ve hafif kalır.

### **📊 Veri ve İstatistikler**
Sistem, aşağıdakileri içeren detaylı ve sayfalanmış JSON dosyaları üretir:
* **Sıralama ve Skor:** Oyuncunun küresel sıralaması ve toplam puanı.
* **Performans Verileri:** Doğruluk oranı (Accuracy), Kazanılan Yıldızlar ve Zorluk seviyesi.
* **Full Combo (FC):** Kusursuz çalma (FC) durumunun tespiti.
* **Oturum Geçmişi:** Sadece en iyi skor değil, detaylı maç istatistikleri.

### **🔒 Güvenlik ve Gizlilik**
* **Kişisel Veri Yok:** Bu proje sadece oyun içinde **herkesin görebildiği** halka açık verileri (Kullanıcı Adı, Skor) işler. E-posta, şifre veya ödeme bilgileri gibi verilere erişilmez.
* **Güvenli Anahtarlar:** Tüm hassas giriş bilgileri (Refresh Tokenlar, Şifreler) **GitHub Secrets** içerisinde saklanır ve asla kaynak kodda görünmez.
